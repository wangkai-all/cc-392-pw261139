Storage and read cost

      
Both strategies are shown concretely: (A) keep the immutable source bytes and
        store an offset mapping per index; (B) lock citations to the source revision they were
        created against. Reading a report is a single SQLite row read + pinned offsets; comparing
        across rulesets costs a scan of the target index's paragraph texts.
